# pwa-design-system

The shared design system of the six offline PWAs. Plain CSS and ES modules; no build
step and no dependencies. It has no app and no deploy.

## Commands

```sh
npm test         # unit tests (node --test)
npm run serve    # http://localhost:8090
```

## Conventions

Read `.claude/conventions/` (loaded at session start): GIT, WRITING, CANONICAL,
WORKFLOW, AUTONOMY, ARCHITECTURE, RELEVANT-FILES.
